# Security Policy

## Current status

Cofferwire is in its design phase and has not received an external security review. Do not use it to protect sensitive or irreplaceable data.

## Reporting a vulnerability

Until a dedicated security contact is published, use GitHub private vulnerability reporting for the repository. Do not open a public issue for an unpatched vulnerability or include real user data, production credentials or private keys in a report.

A useful report includes the affected specification or implementation version, impact, reproduction steps and any suggested mitigation. Receipt and remediation timelines will be added before the first public implementation release.

## Security claims

Security claims must cite the applicable threat-model section and protocol version. End-to-end encryption does not automatically hide IP addresses, timing, message sizes, queue access patterns or blob access correlation.

# cofferwire-crypto

组合标准密码学 primitive，实现 relay command authentication、authenticated HPKE message、
encrypted blob 和 application receipt；不负责 key storage 或 metadata anonymity。

设计见 [`docs/detailed_design/30_密码学.md`](../../docs/detailed_design/30_密码学.md)，规范见
[`docs/spec/04-cryptographic-profile.md`](../../docs/spec/04-cryptographic-profile.md)。

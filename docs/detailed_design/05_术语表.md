# 术语表

规范性定义以 [`../spec/01-terminology.md`](../spec/01-terminology.md) 为准；本表
用于快速定位实现和区分容易混淆的工程概念。

| 术语 | 说明 |
|---|---|
| queue-v1 | 小消息协议的冻结 scope；identifier registry 见 [`docs/spec/10`](../spec/10-versioning.md)，不是所有 Cofferwire profile 的总称 |
| Relay | 不受信任的可用性服务，只持久化 opaque payload 并执行授权状态机；实现见 [`Relay`](../../crates/cofferwire-relay/src/lib.rs) 与 [`DurableRelay`](../../crates/cofferwire-relay/src/durable.rs) |
| Principal | queue 命令认证使用的队列作用域公钥身份；类型见 [`ids.rs`](../../crates/cofferwire-types/src/ids.rs)，不等同于全局用户身份 |
| QueueId | 单个接收设备队列的不可预测标识；多设备各有独立队列 |
| RequestId | 同一认证主体下请求重放和响应关联标识；持久 replay 记录由 Relay 管理 |
| MessageId | SEND 幂等性和应用消息关联标识；不能与 RequestId、QueueId 或 family-tree object ID 混用 |
| relay ACK | 接收方在本地持久提交后授权 Relay 删除消息；见 [`Recipient::poll`](../../crates/cofferwire-client/src/lib.rs) |
| `receipt.applied` | 端到端签名的应用层“已应用”证明，与 relay ACK 语义不同；见 [`receipt.rs`](../../crates/cofferwire-client/src/receipt.rs) |
| Transport | 客户端移动一个完整 opaque frame 的可替换接口；见 [`Transport`](../../crates/cofferwire-client/src/lib.rs) |
| InboxStore | 接收方原子持久化和幂等应用边界；成功返回后才允许 relay ACK |
| capability | blob/1 对上传、下载、续租和删除分别授权的角色化凭证；类型见 [`blob.rs`](../../crates/cofferwire-types/src/blob.rs) |
| BlobId | 由完整加密对象内容确定的标识，与 capability 分离 |
| offline bundle | 永不发送给 Relay 的本地引导/恢复文件；实现见 [`offline.rs`](../../crates/cofferwire-client/src/offline.rs) |
| application profile | 使用 core primitives、但不分配 core identifier 的应用约定；首个实例见 [`family-tree-v1.md`](../../profiles/family-tree-v1.md) |
| canonical CBOR | queue-v1 限定的数据模型和唯一编码；codec 只实现该子集，不是通用 CBOR 库 |
| conformance registry | 将规范性 ID 映射到可执行测试的登记表；见 [`registry.json`](../../conformance/registry.json) |
| release gate | [`TESTING.md` §12](../../TESTING.md#12-release-gates) 定义的正式发布必要条件；本地测试通过不自动等于全部 gate 通过 |

# 配置参考

本项目没有 `.env` 配置层。reference daemon 使用位置参数，测试/证据脚本使用少量显式
环境变量。默认值和限制的一次信息源是相应源码及
[`operational-limits-v1.json`](../../conformance/evidence/operational-limits-v1.json)，本表不复制它们。

## 1. `cofferwired` 参数

解析实现：[`Arguments::parse`](../../apps/cofferwired/src/main.rs)。

| 顺序 / 名称 | 作用 | 约束 |
|---|---|---|
| `BIND_ADDRESS` | daemon 监听 socket address | 必须可解析为 `SocketAddr`；生产公开地址应由防火墙和 proxy 策略约束 |
| `DATABASE_PATH` | queue/blob/replay SQLite 文件 | 单 daemon 实例独占操作；备份前按 runbook 停机 |
| `CERTIFICATE_PEM` | TLS certificate chain 文件 | PEM；签发、续期和权限由运营者管理 |
| `PRIVATE_KEY_PEM` | TLS private key 文件 | PEM；不得提交仓库、日志或公开证据 |

多余或缺少参数会直接拒绝启动。daemon 当前没有运行时覆盖 frame、连接、timeout、rate
或 quota 常量的选项；修改这些行为需同步源码、机器限制清单和测试。

## 2. Line relay 参数

实现：[`cofferwire-line-relay.rs`](../../apps/cofferwired/src/bin/cofferwire-line-relay.rs)。

| 参数 | 作用 | 约束 |
|---|---|---|
| `DATABASE` | conformance line transport 的 SQLite 文件 | 仅诊断/互操作用途，不提供 TLS 网络服务 |

## 3. Fuzz 环境变量

入口：[`fuzz_smoke.sh`](../../scripts/fuzz_smoke.sh)、
[`collect_fuzz_evidence.py`](../../scripts/collect_fuzz_evidence.py)。

| 名称 | 作用 | 影响范围 |
|---|---|---|
| `COFFERWIRE_FUZZ_SECONDS` | 每 target 本次运行预算 | fuzz runner / evidence |
| `COFFERWIRE_FUZZ_RSS_MB` | libFuzzer 内存边界 | fuzz runner / evidence |
| `COFFERWIRE_FUZZ_TIMEOUT_SECONDS` | 单输入 timeout | fuzz runner / evidence |

## 4. 互操作环境变量

| 名称 | 作用 | 影响范围 |
|---|---|---|
| `COFFERWIRE_MATRIX` | 标记由矩阵 runner 启用的跨实现测试 | Rust/Python interop tests |
| `COFFERWIRE_RUST_LINE_RELAY` | 指向已构建 Rust line-relay binary | independent Python → Rust relay |
| `COFFERWIRE_PYTHON` | 指定 Rust 测试调用的 Python executable | Rust client → independent relay |

一次信息源：[`run_interop_matrix.py`](../../scripts/run_interop_matrix.py) 与
[`python_interop.rs`](../../crates/cofferwire-client/tests/python_interop.rs)。

## 5. Release build 环境

| 名称 | 作用 | 约束 |
|---|---|---|
| `SOURCE_DATE_EPOCH` | 将 clean build 绑定到 candidate commit 时间 | 两环境使用相同 revision 派生值 |
| `RUSTFLAGS` | remap build path 并按发布策略处理符号 | 两环境必须使用完全相同值并公开记录 |

具体命令和签名输入见 [`90_部署与运维.md`](90_部署与运维.md)。发布私钥
没有环境变量约定，必须以外部受控文件路径显式传给 `ssh-keygen`。

## 6. CI 一次信息源

稳定测试工具链、Python 安装和 scheduled fuzz budget 以
[`ci.yml`](../../.github/workflows/ci.yml) 与 [`fuzz.yml`](../../.github/workflows/fuzz.yml)
为准。文档不复制 action 默认值或 transient runner 配置。
